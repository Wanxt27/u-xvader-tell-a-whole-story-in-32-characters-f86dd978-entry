A make.fun entry for [Tell a Whole Story in 32 Characters](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978).

`main.ts` (Node 22, stdlib only) writes one Wi-Fi network name — 30 characters — to `/output/entry.txt`:

> I moved out, kept the password

The story in one line: a breakup, a move-out, and the petty victory of walking away with the one thing that still matters — the password. The narrator is gone, but they are still on the network.

Run it with:

```sh
node main.ts
```
